# tdxline.dat 二进制格式逆向笔记

> 来源：对通达信客户端真实文件的对照实验逆向（2026-10）。
> 适用版本：通达信 v2017+（`new_tdx/new/T0002/tdxline.dat` 与 `T0002/tdxline.dat` 同构）。

## 总体结构

- 文件由**固定 378 字节的记录**顺序串联，每条记录 = 一条画线；
- 记录数 = 文件大小 / 378（例：14,501,970 字节 = 38,365 条）；
- 新画的线**追加在文件末尾**；删除画线后记录被复用/清零。

## 记录布局（378 字节，小端）

| 偏移 | 大小 | 含义 | 已验证 |
|---|---|---|---|
| 0x00 | 1 | 记录标志，恒为 `0x01` | ✅ 全量 |
| 0x01 | 23 | 证券代码 ASCII，`00` 填充（如 `600519`） | ✅ 全量 |
| 0x18 | 1 | 恒为 `0x02` | ✅ |
| 0x19 | 8 | 线组名 ASCII（如 `STANDK`，画线所在指标页/周期组） | ✅ |
| 0x21 | 0x35 | 全 0（未知，可能保留/扩展） | — |
| 0x56 | 4 | float32 价格 Y1 | ✅ |
| 0x5A | 4 | float32 价格 Y2 | ✅ |
| 0x5E | 5 | 全 0 | — |
| 0x63 | 1 | **画线类型**：`0x02` = 水平线，`0x07` = 线段（其余类型待采样） | ✅ |
| 0x64 | 1 | 颜色索引（默认 0） | 待验证 |
| 0x65 | 4 | uint32 锚点 1 的 **K 线序号**（bar index） | ✅ |
| 0x69 | 2 | 锚点 1 **紧凑日期**：`year=u//2048+2004, month=u%2048//100, day=u%2048%100` | ✅ 全量通过 |
| 0x6B | 2 | 锚点 1 **时间**（分钟数，`0x0384=900`=15:00；日线通常 900） | ✅ |
| 0x6D | 4 | float32 锚点 1 价格 | ✅ |
| 0x71 | 8+ | 锚点 2，与类型相关：线段 = `(uint16 date, uint16 time, float32 price)` @0x75 前有 4 字节 x；水平线 = `uint32 x2`（延伸范围） | 部分 ✅ |
| 0xC9+ | — | 尾部：`01 00 00 00 01 00 00 00 0A 00 00 00 FF FF FF 00` 等样式/标志（`FFFFFF`=RGB 白） | 待验证 |

## 日期紧凑编码（与分钟线 .lc1/.lc5 同族）

```
u = (year - 2004) * 2048 + month * 100 + day
year = u // 2048 + 2004
month = (u % 2048) // 100
day = (u % 2048) % 100
```

例：`0xA396` = 41878 → 2024-09-18；`0xB3F6` = 46070 → 2026-10-14。

### 关键新发现

1. **@0x71 不是 bar 索引，是"记录自编号"**：四轮画线依次为 0x95DC(38364)、
   0x95DD、0x95DE、0x95DF —— 正好等于各块在文件中的块序号（从 0 计）。
   写入新记录时此字段 = 该块在文件中的下标。
2. **图形对号（用户确认）**：
   - 块0 = **线段**：Y1=1181.64, Y2=1367.85，x1=bar 4106，双锚点；
   - 块1 = **矩形**：Y1=1391.60, Y2=1321.62（上下边价格），双锚点；
   - 块2 = **文字**（内容"开源"）：单锚点，Y1=1238.14，x1=bar 4118（=2026-08-27 ✓），
     Y2=0，文字内容**不在本块明文区**（378 字节内未发现 GBK/UTF-8"开源"），
     可能存于云端配套文件或编码在样式区，待查。
3. **@0x69 的 4 字节**：线段/矩形/文字样本（0x01352766 / 0x01352779 / 0x013527DB）
   差值分别为 19、98 —— 与用户点击间隔（秒级）吻合，疑似**创建时刻计数器**，
   与锚点吸附时间（第一轮水平线的 2026-10-14 15:00 可正常解码）语义不同；
   对导入器而言可照抄模板值或按同规则生成。
4. 0x0C8 起 flags：`01 00 00 00 01 00 00 00 (0A|00) 00 00 00 FF FF FF 00`，
   `FFFFFF` 为 RGB 白色；0xE5 附近还有一个 `0x0135289B` 型 u32。
5. **类型码现状**：水平线=0x02；线段/矩形/文字本轮头部均为 0x04，
   需继续寻找真正的区分字段（可能在 0x5E-0x62 或样式区）。
